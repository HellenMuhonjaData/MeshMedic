label_information_sources — every line of the note, and every code and care gap, labeled by source. From encounter: said in the transcript or on the chart (the matching transcript line is shown). AI-generated: the AI added it — check it before relying on it. Clinician-entered: added by a clinician while editing. Each time labels are shown, the source of every item is written to the audit trail.

3 Suggested codes

suggest_codes / approve_codes — ICD-10 / CPT, reviewed the same way as the note. You (the clinician) enter the code and its description; grey text is only an example.

4 Care gaps

identify_care_gaps / address_care_gap — each gap is flagged and closed independently.

5 Continuity — orders & follow-up

order_test / record_test_result / get_pending_items_for_patient — what a returning patient's next visit sees from this one.

6 Referral letter

generate_referral_letter / approve_referral_letter — drafted from the approved encounter note. Review and edit it, then approve to mark it ready to send. Both steps are written to the audit trail.

Print and Download appear once the letter is approved. Check the Patient line matches who you're referring before you do.

MeshMedic doesn't deliver letters. Print or download it, send it yourself, then record how it went out.

Letters ready to send (all patients)

list_referral_letters / mark_referral_letter_sent — every approved letter not yet sent, across all patients, so nothing approved gets forgotten once its encounter is closed.

7 Citation check

request_citation — proves a claimed excerpt genuinely appears in the transcript, or says honestly that it doesn't.
